تشغيل خادم ووردبريس ومجمع الأخبار كخدمة تلقائية (Cron Job)

1. تشغيل العملية التلقائية عبر المنفذ الصامت (CLI Cron)

يمكنك جدولة المجمع للعمل كل 15 دقيقة صامتاً دون تشغيل لوحة التحكم، وذلك لتحديث موقعك بالأخبار باستمرار:

node index.js --cron

2. جدولتها في أنظمة Linux / Unix (Crontab)

افتح ملف الجدولة عبر crontab -e ثم أضف السطر التالي للتشغيل التلقائي كل 15 دقيقة:

*/15 * * * * cd /path/to/syrian_news_aggregator && node index.js --cron >> cron_logs.log 2>&1

3. جدولتها في أنظمة Windows (Task Scheduler)

افتح مجدول المهام (Task Scheduler) في ويندوز وقم بإنشاء مهمة جديدة:

  • الإجراء (Action): بدء برنامج (Start a Program)
  • البرنامج/البرمجة (Program/Script): node
  • الوسيطات (Add Arguments): index.js --cron
  • الدليل الافتراضي (Start in): المسار الكامل لمجلد syrian_news_aggregator
  • المشغل (Trigger): التكرار كل 15 دقيقة بشكل مستمر.

إذا كنت تفضل جدولة هذه العملية بالكامل وبصرياً عبر n8n، فقد وفرنا لك تكاملاً متكاملاً بمستوى احترافي عالي الدقة:

مخطط n8n الجاهز للاستيراد الفوري

ستجد ملفاً جاهزاً باسم n8n_workflow.json داخل مجلد المشروع.

دليل n8n التفصيلي المتكامل

قم بفتح الملف الإرشادي المخصص n8n_guide.md لتتعلم كيفية رفع المخطط وتهيئة خيارات الحساب والاتصال خطوة بخطوة بالصور التوضيحية.

نصيحة ذهبية: يتيح لك تكامل n8n تتبع العملية بصرياً بالكامل والربط مع خدمات أخرى كإرسال الأخبار لقنوات التليجرام أو الواتساب أو تويتر فور نشرها بالووردبريس تلقائياً!
